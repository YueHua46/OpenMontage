# 产品品类指南（Categories）

每个文件沉淀**某一类产品**在 AI 视频生成中的物理结构规律、常见翻车点、高危动作替代拍法、专用合成工具及可复用的 `checks` 验收模板。

与风格模板（`references/styles/`）的分工：
- **风格模板（`styles/`）** 管“片子拍出来像什么观感与节奏”（例如 TikTok 手机实拍风 vs 精致棚拍广告风），跨品类通用。
- **品类指南（`categories/`）** 管“这类商品本身的物理结构、安装/使用方式、参照系与功能演示拍法”，跨风格通用。
- **方法卡（`playbooks/`）** 管“某一条具体跑通片子的分镜结构与提示词实例”，用于同系列批量复制；具体某款 SKU 的实测厘米尺寸只写进项目 `shots.json` 或方法卡，不写进本目录。

## 怎么用

1. **按需加载：** 看素材与写提案前，对照上表判断本片商品是否命中现有品类。命中时**完整阅读对应品类文件**，并在提案中说明选用了哪个品类指南；spec 顶层可记录 `"category": "<文件名，不含 .md>"`（如 `"category": "security-camera"`）。
2. **未命中时不硬套：** 做其他公司或新类目的产品（如厨电、个护美妆、服饰箱包、普通家居品）且尚无对应文件时，**不要加载无关品类的文件**，直接按 `SKILL.md` 和 `references/batch.md` 的通用物理、尺度与连续性规则执行。
3. **优先级：** 用户提供的真机实拍资料、明确产品参数和完整原稿剧本优先于品类默认建议；品类指南用于帮你在不删改剧情的前提下，把高危镜头改成模型拍得真、物理上站得住的做法。

## 怎么新增或补充品类

1. **补充现有品类：** 项目中发现只属于某类产品的结构、视角或功能演示新问题，当轮提炼成通用规律（不写具体项目代号或 `take` 流水账），补进对应品类文件。
2. **新增品类文件：** 当某一新品类跑通至少一条用户验收通过的成片、且积累了该类产品独有的物理约束时，可参照 `security-camera.md` 的结构新建文件（适用范围 → 硬件/材质结构红线 → 尺度与场景位置 → 运动与参照系 → 高频功能拍法 → 专属故障速查 → 默认 `checks` 模板），并登记到本页表格中。通用流程、预算闸门与修复禁令不要在品类文件里重复。
