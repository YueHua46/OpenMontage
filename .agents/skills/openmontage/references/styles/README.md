# 风格模板

每个文件是一种画面风格的做法：适用场景、片子结构、画面要求、提示词写法、要加进 spec 的验收规则。不同用户、不同片子要的风格不一样，所以这些要求不写进通用流程，按需选用。

## 现有模板

| 文件 | 风格 | 用户这样说时用 |
|---|---|---|
| `tiktok-ugc.md` | TikTok / Reels 引流带货，手机实拍感 | “TK”“TikTok”“引流”“带货短视频”“要像真人拍的”“分不出是 AI” |

## 怎么用

1. 提案时按用户的说法选模板，告诉用户选了哪个、为什么；用户要的风格和模板冲突时，以用户为准。
2. spec 顶层写 `"style": "<文件名，不含 .md>"`。
3. 按模板写提示词，把模板里的验收规则加进 spec 的 `checks`（可按片子改写）。
4. 没有合适模板时，按用户的描述写提示词和 `realism` 规则，不要硬套现有模板。

## 怎么新增

一种风格做出过验收通过、用户满意的片子后，可以新增模板。照 `tiktok-ugc.md` 的小节写：适用、结构、画面要求、提示词写法、验收规则、要向用户要的素材。只写这种风格独有的要求，通用流程（参考图、验收闭环、修复边界）不要重复。

方法卡（`playbook.py`）和风格模板的区别：方法卡是从一条具体片子沉淀的做法，带当时的产品、镜头和提示词示例，用于批量出同类片子；风格模板是跨产品通用的观感和写法，开一条新片子时就能用。
